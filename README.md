# 결혼 플랜 대작전

웨딩홀·스드메 비교, 플래너, 혼수 준비, 계산기, 실제 상담 견적 비교까지 한 번에 관리하는 결혼 준비 웹앱입니다.

- 로그인(회원가입) 후 데이터는 Supabase에 자동 동기화되어 PC·모바일 어디서 접속해도 항상 최신 상태를 볼 수 있습니다.
- `supabase_schema.sql`: Supabase 프로젝트에 한 번만 실행하면 되는 테이블 생성 스크립트입니다. (로그인 기능 추가로 구조가 바뀌었으니, 이전 버전의 SQL을 이미 실행하셨다면 `drop table if exists whg_sync;`를 먼저 실행한 뒤 이 스크립트를 실행해주세요.)
- `index.html`: 배포되는 실제 페이지입니다. GitHub Pages로 서빙됩니다.

## 실제 배포(상용화) 전 체크리스트

- Supabase 대시보드 → Authentication → Providers → Email 설정에서 "Confirm email"을 켜둘지 끌지 결정해주세요. 꺼두면 회원가입 즉시 로그인되고, 켜두면 이메일 인증 링크를 눌러야 로그인할 수 있습니다(두 분만 쓰는 계정이라면 꺼두는 쪽이 더 간편해요).
- "비밀번호를 잊으셨나요?" 버튼은 Supabase의 기본 비밀번호 재설정 이메일을 보내는데, 실제 메일이 발송되려면 Supabase 프로젝트의 이메일 발송 설정(SMTP)이 되어 있어야 합니다. 기본 제공되는 Supabase 발신 메일은 일일 발송 한도가 낮으니, 본격적으로 쓰기 전에 한 번 "비밀번호를 잊으셨나요?"로 테스트 메일을 받아보시는 걸 권장해요.
- 두 분이 각자 다른 기기에서 거의 동시에 수정해도 서로의 변경사항을 지우지 않도록 동기화 로직을 보강했습니다(항목 단위 병합). 그래도 정말 같은 순간에 같은 항목을 동시에 고치면 나중에 저장한 쪽이 우선합니다 — 실무상 거의 일어나지 않는 경우예요.
